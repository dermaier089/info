Wie ich mit Claude Code ein Audio-Transkriptions-Tool gebaut habe

Ohne Programmierkenntnisse. Einfach durch ein Gespraech.

Das hier ist die Geschichte eines echten Dialogs. Ich zeige dir Schritt fuer Schritt, wie Claude Code mir geholfen hat — und wie du das Gleiche machen kannst.

Der Anfang

Ich hatte ein einfaches Problem

Ich hatte MP3-Dateien — aufgenommene Gespraeche — und wollte die als Text haben. Keine Ahnung wie. Also hab ich einfach Claude gefragt:

Ich
Ich habe MP3-Dateien (Gespraeche), die moechte ich als Textdatei haben.

Das wars. Kein technisches Wissen noetig. Einfach sagen, was man will.

Claude reagiert

Claude fragt nach & schlaegt vor

Claude hat nicht einfach irgendwas gemacht. Er hat zuerst gefragt, was mir am besten passt:

Claude
Welchen Ansatz bevorzugst du?
❯ Whisper (lokal, kostenlos)
❯ faster-whisper
❯ Azure Speech Service
Ich
Whisper, lokal und kostenlos klingt gut.

Dann hat Claude selbststaendig geprueft, ob Python installiert ist, Whisper installiert, und die Transkription gestartet.

Ergebnis

Nach ein paar Minuten: fertig

Claude hat alles alleine gemacht:

✓ Python gecheckt
✓ Whisper installiert
✓ Meine MP3-Datei transkribiert
✓ Text als .txt gespeichert (21.000 Zeichen)

Ich musste nichts selber tippen oder installieren. Claude hat meinen Computer benutzt und alles eingerichtet.

Plot Twist

Ich habe nachgefragt — Claude hat optimiert

Mir ist aufgefallen, dass es auf der CPU lief statt auf der Grafikkarte. Also habe ich einfach gefragt:

Ich
Warum lief es nicht auf GPU?
Claude
Deine Python-Version (3.14) ist zu neu — PyTorch bietet dafuer noch keine GPU-Unterstuetzung. Loesung: Python 3.12 parallel installieren.
Ich
Dann downgraden.

Claude hat Python 3.12 installiert, PyTorch mit GPU-Support eingerichtet, und alles getestet. 5-10x schneller.

Die Idee

Ich will das oefter machen — was nun?

Jetzt kam der spannende Teil. Ich wollte das nicht jedes Mal manuell machen:

Ich
Ich moechte so etwas oefter machen. Audiodateien transkribieren und die Texte dann per AI checken lassen. Was waere best practice? Ein Skill?
Claude
Ja, ein Skill ist hier die beste Wahl! Damit kannst du z.B. /transcribe ~/aufnahmen aufrufen und er transkribiert alle Dateien und analysiert sie.

Claude hat dann nachgefragt, was genau ich brauche — Analyse-Art, Formate, Output-Format, Modellgroesse.

Erklaerung

Was ist ein "Skill"?

Ein Skill ist wie ein Kurzbefehl fuer Claude Code. Statt jedes Mal alles zu erklaeren, tippst du einfach:

/transcribe ~/Desktop/aufnahmen

Und Claude weiss sofort:

❯ Welches Tool er nutzen soll (Whisper)
❯ Welche Einstellungen (Modell, Sprache)
❯ Was er mit dem Ergebnis machen soll (AI-Analyse)
❯ Wo er die Ergebnisse speichern soll

Claude erstellt den Skill fuer dich — du musst ihn nicht programmieren.

Das Prinzip

So arbeitet man mit Claude Code

1. Sag was du willst — in normaler Sprache

2. Claude fragt nach, wenn etwas unklar ist

3. Claude setzt es um — installiert, programmiert, testet

4. Du sagst, was nicht passt — Claude verbessert

5. Wenns oefter gebraucht wird → Skill erstellen lassen

Du brauchst kein IT-Know-how. Du musst nur wissen, was du willst. Claude kuemmert sich um das Wie.
